| 1 | 用户系统范围 | 真手机号验证码登录 + 头像/昵称云端；**账目数据仍纯本地**，本次不做云同步 |

## 需求 2：个人页折叠 + 功能模块开关

### 2a. 页面折叠
个人页（Profile）改为两级结构：

- **一级（门面）**：头像/昵称展示区、🔐 权限设置 入口卡、🙋 个人中心 入口卡、版本号
- **二级 A `/profile/permissions`（权限设置）**：短信自动记账（现有 SmsAutoPanel）、通知权限、精确闹钟、节假日日历同步 —— 只放"系统授权"类
- **二级 B `/profile/center`（个人中心）**：头像昵称、界面主题、功能模块开关、小猪按钮设置、自动记账设置（总开关/确认策略/AI 开关/标签规则）、记账模式、智能推荐开关、标签管理、数据同步与备份（占位）、版本

### 2b. 功能模块开关
- 存储：`pigbaby_features` = `{ accounting: boolean, tasks: boolean }`，默认两者都开
- 个人中心内三态选择：仅记账 / 仅任务 / 两者都要
- 导航栏按开关渲染（**日历、个人固定保留**）：
  - 都要：记账 | 日历 | 🐷 | 任务 | 个人（现状）
  - 仅记账：记账 | 日历 | 🐷(记支出) | 个人
  - 仅任务：任务 | 日历 | 🐷(建任务) | 个人
- 当前停在被关闭模块的页面时，自动跳回可用页面；默认路由按开关重定向
- **日历解耦**：现在"日历"是任务页的一个子标签（`/tasks?view=calendar`），需抽出为独立组件与独立路由 `/calendar`。独立后的日历 = 完整月历 + 节假日 + 当日备注 + （有任务模块时）当日任务列表；仅记账模式下不显示任务区
- 小猪触发选项随开关自适应（见需求 5）

## 需求 10：标签表与重命名

- 新存储 `pigbaby_tags_v2`：
  ```
  { expense: TagDef[], income: TagDef[] }
  TagDef = { name, color, order }
  ```
- 首次启动迁移：`DEFAULT_TAGS + pigbaby_custom_tags` → expense 表；颜色合并 `TAG_COLORS + pigbaby_tag_colors`；备注记忆 `pigbaby_tag_notes` 的键随重命名同步更新
- 老存储键保留读取兼容，迁移后以新键为准
- **标签管理页**（个人中心入口）：新增 / 重命名 / 换色 / 删除
  - 重命名：同步更新 ①标签表 ②全部历史记录 `record.tag` ③颜色映射 ④备注记忆 ⑤自动记账商户规则（需求 6）
  - 删除：仅从可选列表移除，历史记录保留原标签名（与现状一致）
- AddRecordModal 的"+ 自定义"逻辑改为写入标签表

## 需求 4：收入独立标签体系

- `Transaction.tag` 对收入生效；旧收入记录 `tag:''` 视为"其他"（显示层兜底）
- 收入默认标签：工资、红包、理财、报销、转账、其他（可在标签管理中增删改）
- 影响面：
  - AddRecordModal：收入也显示标签选择器（收入标签集）
  - 记录列表：收入显示标签 chip（现在只有 💰 图标）
  - 按日查询：增加"当日收入分类"柱状图（与支出对称）
  - 标签统计页：增加 收入/支出 切换，分别统计
  - `smsAuto.ts buildTransactions`：收入短信记录同样走标签规则

## 需求 3：打卡天数直接输入

- CheckIn 目标编辑弹窗：−/+ 按钮改为数字输入框，范围 周 1-7 / 月 1-31，越界自动夹取

## 需求 8：按日柱状图翻转

- DailyRecords 分类条：横向（width%）→ 竖向柱状（height%，自下而上）
- 标签在柱底，金额在柱顶，点柱仍可筛选明细

## 需求 5：中心小猪可配置

- 存储 `pigbaby_pig_action` = `'expense' | 'task'`，默认 expense
- 个人中心内单选：记支出 / 创建任务
- 仅开启单一模块时固定为该模块动作（不显示无意义的选项）

## 需求 7：记账模式（预算制 ↔ 余额制）

- 存储：`pigbaby_money_mode` = `'budget' | 'balance'`；`pigbaby_initial_balance` = `{ amount, fromDate }`
- **预算制（现状）**：本月剩余 = 月预算 + 本月收入 − 本月支出
- **余额制（新增）**：
  - 首次切换弹窗输入「当前余额」，同时记录生效日期 `fromDate`
  - 余额 = 初始余额 + （fromDate 起的所有收入 − 支出）
  - 主页卡片改为两块：**余额**（大字）+ **本月支出**（副卡）；月预算降级为"本月支出/月预算"进度条（可选显示）
  - 不再显示"本月剩余"
- 存钱罐页的数值语义跟随模式（预算制=本月剩余；余额制=总余额）
- 参考主流 App（钱迹资产卡 + 月支出卡）的两块式布局

## 需求 9：记账记忆（智能推荐）

- 数据来源：**直接从历史记录实时推导**（备注→标签、标签+时段→备注、金额同档位），不再依赖单独计数器，新旧数据一致
- 推荐内容：
  - 输入备注时实时推荐标签（历史同备注高频标签优先）
  - 备注推荐：按 标签 + 时段（早/中/晚）+ 使用频次 综合排序（替代现有"常用备注"的纯频次）
- 与需求 6 共用同一引擎：自动记账草稿的打标顺序 = 商户规则 → 本记忆引擎 → （可选）AI
- 个人中心开关「智能推荐」，默认开

# 第二批（v1.8.0）：需求 6 自动记账

按 [自动记账设计方案.md](./自动记账设计方案.md) 落地，仅确认策略改为：

- **所有捕获（支出/收入/转账）→ 生成"待确认"草稿**，逐笔确认后入账
- 个人中心「自动记账」设置：总开关、**跳过确认直接入账**（关闭确认）、AI 增强开关、商户→标签规则管理
- 打标顺序：商户规则 → 记账记忆引擎（需求 9）→ AI（若开启）
- 保留：「最近捕获」调试页（解析校准用）、跨通道去重（短信+通知 ±10min）、原生侧持久化

# 第三批（v2.0.0）：需求 1 用户系统

- 方案：腾讯云开发 CloudBase
  - 手机号 + 短信验证码登录（CloudBase 短信登录能力）
  - 头像上传 → 云存储；昵称 → 云数据库用户表
  - 账目数据仍在本机 Preferences，不上云
- 前端接入 `@cloudbase/js-sdk`，Capacitor WebView 内运行
- UI：登录/注册页（未登录时）；个人页头像昵称改为云端资料，支持更换头像、改昵称、退出登录
- 花费：短信约几分钱/条 + CloudBase 按量（初期每月几元级）
