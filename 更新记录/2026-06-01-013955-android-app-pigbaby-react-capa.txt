❯ 请帮我创建一个 Android App 项目，名叫 PigBaby，使用 React + Capacitor         
  技术栈。                                                                      
                                                                                
  ## 项目结构                                                                   
  - 使用 React + TypeScript                                                     
  - 使用 Capacitor 打包成 Android APK                                           
  - 使用 Capacitor Preferences API 做本地数据存储                               
  - 底部导航切换两个模块：记账管理和任务管理                                    
  - 初版只实现记账管理，任务管理显示占位页面                                    
                                                                                
  ## 记账管理功能                                                               
  ### 主界面                                                                    
  - 顶部显示当前月份（如"2026年6月"）                                           
  - 中间大卡片显示"本月剩余"金额，醒目突出                                      
  - 卡片内同时显示月预算和已支出金额                                            
  - 两个按钮："记收入"和"记支出"                                                
  - 下方显示最近记录列表，每条显示类型图标、金额、备注、日期                    
  - 收入显示绿色+号，支出显示红色-号                                            
                                                                                
  ### 记收入/支出弹窗                                                           
  - 弹窗形式，包含金额输入框、备注输入框、日期选择器                            
  - 日期默认当天                                                                
  - 确认后保存到本地存储，关闭弹窗，刷新主界面                                  
                                                                                
  ### 数据逻辑                                                                  
  - 月预算默认为3000元，可在设置中修改                                          
  - 本月剩余 = 月预算 + 本月收入总额 - 本月支出总额                             
  - 所有数据按月管理，切换月份显示对应数据                                      
                                                                                
  ### 技术细节                                                                  
  - 使用 Capacitor Preferences API 存储所有数据                                 
  - JSON 结构包含 monthlyBudget 和 records 数组                                 
  - 支持导出数据为 JSON 文件备份                                                
  - 底部导航占比小，主体内容占比大                                              
  - 移动端优先的 UI 设计，大按钮适合手指点击                                    
                                                                                
  ### 任务管理模块                                                              
  - 初版显示"任务管理即将上线"的占位页面                                        
                                                                                
  请完整实现以上功能，并配置好 Capacitor 安卓打包。
