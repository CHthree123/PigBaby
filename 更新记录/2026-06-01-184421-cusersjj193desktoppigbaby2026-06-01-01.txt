● 根据对话记录，整个 PigBaby App 是这样一步步搭建出来的：

  ---
  第1步：创建 React + TypeScript 项目

  用 Vite 脚手架初始化项目：

  mkdir PigBaby && cd PigBaby
  npm create vite@latest . -- --template react-ts
  npm install

  这生成了一个标准的 React + TypeScript 项目骨架。

  ---
  第2步：安装 Capacitor 和路由依赖

  npm install @capacitor/core @capacitor/cli @capacitor/preferences
  @capacitor/android react-router-dom

  - @capacitor/core + @capacitor/cli — Capacitor 核心，负责把网页打包成 App
  - @capacitor/preferences — 本地键值存储，用来存记账数据
  - @capacitor/android — Android 平台支持
  - react-router-dom — 前端路由，用于底部导航切换页面

  ---
  第3步：初始化 Capacitor

  npx cap init PigBaby com.pigbaby.app --web-dir=dist
  npx cap add android

  - 第一条命令生成 capacitor.config.ts 配置文件，指定应用名和包名
  - 第二条命令创建 android/ 目录，里面是完整的 Android 原生项目

  ---
  第4步：编写数据存储层 (src/storage.ts)

  这是整个 App 的数据基础。封装了 Capacitor Preferences API：

  - 定义了 Record 接口（id、金额、类型、备注、日期、月份）
  - 定义了 AppData 接口（monthlyBudget 月预算 + records 记录数组）
  - loadData() — 从本地读取所有数据
  - saveData() — 保存数据到本地
  - exportData() — 导出为 JSON 文件下载

  数据按月份组织，每条记录标记了所属月份。

  ---
  第5步：搭建 App 壳子 (src/App.tsx + src/main.tsx)

  - main.tsx — 入口文件，挂载 BrowserRouter 包裹整个应用
  - App.tsx — 主布局：
    - 上方 <Routes> 切换页面（记账页 / 任务页）
    - 下方固定底部导航栏，两个按钮："记账"和"任务"

  CSS 采用移动端优先设计，主体内容区域占大部分空间，底部导航小而紧凑。

  ---
  第6步：实现记账管理页面 (src/pages/Accounting.tsx)

  这是核心页面，200多行代码：

  顶部月份切换： 左右箭头按钮切换月份，标题显示"2026年6月"格式

  余额卡片：
  大字号渐变背景卡片，突出显示"本月剩余"金额，下方小字显示月预算和已支出

  记收入/记支出按钮： 两个大按钮，点击弹出底部弹窗

  记录列表： 按日期倒序排列，收入显示绿色 + 号，支出显示红色 -
  号，每条显示图标、金额、备注、日期

  设置按钮： 齿轮图标，点击可修改月预算（默认3000元）

  数据导出按钮： 导出 JSON 备份文件

  计算公式： 本月剩余 = 月预算 + 本月收入总额 - 本月支出总额

  ---
  第7步：实现弹窗组件 (src/components/AddRecordModal.tsx)

  底部弹出式弹窗，包含：
  - 金额输入框（数字键盘）
  - 备注输入框
  - 日期选择器（默认当天）
  - 确认按钮 — 生成唯一 ID，保存记录到本地存储，关闭弹窗，刷新页面

  ---
  第8步：实现任务管理占位页 (src/pages/Tasks.tsx)

  简单居中显示"任务管理即将上线"和"敬请期待更多精彩功能"。

  ---
  第9步：编译验证

  npm run build

  修复了 TypeScript 编译错误（删除了未使用的 month prop），确认构建成功。

  ---
  第10步：配置 Android 打包环境

  安装 Android Studio（C:\Android Studio\）

  配置国内镜像加速（因为 Gradle 官方源在国内很慢）：
  - gradle-wrapper.properties — 将 Gradle 下载地址改为腾讯云镜像
  - build.gradle — 添加阿里云 Maven 镜像

  安装 Android SDK 命令行工具：
  # 下载 commandline-tools
  curl -L -o cmdline-tools.zip
  "https://dl.google.com/android/repository/commandlinetools-win-latest.zip"
  # 解压并安装 SDK 组件
  sdkmanager "platforms;android-35" "build-tools;35.0.0" "platform-tools"
  # 接受许可证
  yes | sdkmanager --licenses

  ---
  第11步：打包 APK

  npm run build              # 编译前端
  npx cap sync android       # 同步到 Android 项目
  cd android && ./gradlew assembleDebug  # 打包 debug APK
